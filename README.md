Читай книги

Книжный интернет-магазин. Фронтенд на чистых HTML/CSS/JS, бэкенд  на C#.

Страницы:
home.html — главная (каталог, популярное, акции)
catalog.html — список книг с фильтрами и сортировкой
product.html — страница книги
basket.html — корзина
favourites.html — избранное
profile.html — профиль пользователя
input.html / register.html — вход и регистрация
admin_books.html, add__books.html — админка: список и добавление книг
admin_stocks.html, add__stocks.html — админка: список и добавление акций
Роли:
Пользователь — просмотр каталога, корзина, избранное, профиль
Администратор — управление книгами и акциями

Стек:
HTML, CSS, JavaScript (без фреймворков), C#
